# Lesson 007

**Title:** Standard and Custom Object in Salesforce: How to create a custom object?

## Notes

- Salesforce provides standard Objects (Account, Contact, Lead, etc.).
- Custom Objects store business-specific data not covered by standard Objects.
- Every Object includes standard fields (Name, Id, Created Date, etc.).
- Custom Fields can be added to both Standard and Custom Objects.
- Setup → Object Manager manages Objects.
- Every Object has a Label and an API Name.
- Use the API Name when referencing an Object in Apex.
- Fields are managed in Object Manager → Object → Fields & Relationships.
- Record Name can be Text or Auto Number.
- Auto Number supports display formats (e.g. EN-{000}).
- Reports, Activities, Field History and Chatter can be enabled.
- A Tab can be created during Object creation.
- Tab visibility is configured by Profile.
- Tabs can be added to multiple Apps.
- Custom Object API names end with __c.
- Standard Object API names do not use __c.
