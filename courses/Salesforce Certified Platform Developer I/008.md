# Adding Fields to a Custom Object with Object Manager

## Summary

Object Manager is used to add fields to Salesforce objects. Field data types, security settings, and page-layout placement determine how data is stored and who can access it.

---

## Key Concepts

### Creating Fields

- Create fields from **Setup → Object Manager → Object → Fields & Relationships → New**.
- Every field requires a data type that determines the kind of data it stores.
- Common types include Text, Number, Currency, Phone, Email, Date, Date/Time, Checkbox, Picklist, Formula, Auto Number, Percent, URL, Text Area, Time, and Geolocation.

### Field Settings

- **Required** makes a value mandatory before a record can be saved.
- **Unique** prevents duplicate values and can be case-sensitive or case-insensitive.
- **External ID** identifies records for integrations, imports, and upserts.
- **Auto Number** generates sequential values using a display format, such as `EN-001`.

### Visibility and Layouts

- Field-Level Security determines which profiles can view or edit a field.
- Fields can be added to one or more page layouts during creation.
- A page layout controls how fields appear on a record page.
- Leave **Auto add to custom report types** enabled unless there is a specific reason to disable it.

---

## Certification Tips

- Select a field type based on the data being stored; use Currency for monetary values.
- Required, Unique, and External ID each solve different data-quality or integration needs.
- Field-Level Security controls field access; page layouts control field placement.
- Auto Number creates sequential values according to its display format.

- Field-Level Security controls access, while page layouts control display.
