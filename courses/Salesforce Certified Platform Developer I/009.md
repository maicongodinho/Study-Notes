# Schema Builder in Salesforce: Adding Fields Visually

## Summary

Schema Builder is a visual workspace for reviewing Salesforce objects, fields, and relationships. It also lets administrators create several fields efficiently through drag and drop.

---

## Key Concepts

### Accessing and Viewing the Schema

- Open Schema Builder from **Setup → Objects and Fields → Schema Builder**.
- Use **Select From** to filter the displayed objects, such as Custom Objects only.
- Enable **Display Element Names** to show API names, such as `Employee__c`.
- Enable **Show Relationships** to visualize connections between objects.
- Show or hide the legend, zoom, and navigate around the canvas as needed.

### Creating and Managing Fields

- Drag field types from the **Elements** panel onto an object to create fields.
- Not all Salesforce field types are available in Schema Builder.
- Use an object's gear icon to edit or delete that object.
- Right-click a field to edit its properties, delete it, or manage Field-Level Security.
- Schema Builder is often faster than Object Manager when creating multiple fields.

### Page Layouts and Metadata Updates

- Fields created in Schema Builder are not automatically added to page layouts.
- Add new fields through **Setup → Object Manager → Employee → Page Layouts → Employee Detail**.
- Page layouts let you add, remove, reorder, and organize fields into sections.
- Metadata changes can take a few moments to appear in the user interface.

---

## Certification Tips

- Use **Show Relationships** to document and understand a data model.
- Use **Display Element Names** when API names are needed.
- Add Schema Builder fields to the appropriate page layout before users can see them.
- Schema Builder is useful for quickly creating several fields, but not every field type is available.

## Knowledge Check

### Question 1

An administrator creates a field in Schema Builder, but users cannot see it on Employee records. What should the administrator do?

A. Refresh the browser until the field appears.

B. Add the field to the appropriate page layout. ✅

C. Deploy the object using a change set.

D. Enable Show Relationships.

**Answer:** B

---

### Question 2

Which Schema Builder feature displays links between related objects?

A. Display Element Names

B. Show Relationships ✅

C. Show Legend

D. Field History Tracking

**Answer:** B

---

### Question 3

What is the most efficient way to add many new fields to an existing object during a workshop?

A. Create every field individually in Object Manager.

B. Drag field types onto the object in Schema Builder. ✅

C. Export metadata and edit XML manually.

D. Clone the object and rename the fields.

**Answer:** B

---

### Question 4

A new Schema Builder field is not visible immediately on a record. Which two actions should the developer perform first?

A. Verify that the field was added to the page layout. ✅

B. Wait briefly for metadata changes to propagate. ✅

C. Recreate the field using Object Manager.

D. Delete the browser cache.

**Answer:** A and B

---

### Question 5

Which combination lets an administrator view API names, visualize relationships, and create fields quickly?

A. Enable Display Element Names and Show Relationships, then use the Elements panel. ✅

B. Enable Show Legend and modify the page layout.

C. Use Object Manager exclusively.

D. Enable Display Element Names and create fields using Reports.

**Answer:** A

---

## Key Takeaways

- Schema Builder provides a visual view of objects, fields, and relationships.
- Use Display Element Names for API names and Show Relationships for connections.
- Drag and drop field creation is efficient for multiple fields.
- Add new fields to a page layout before users can see them on records.
