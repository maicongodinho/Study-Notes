# Lesson 008

**Title:** How to add fields to the custom object: Adding fields using Object Manager

## Notes

- Create fields from **Setup → Object Manager → Object → Fields & Relationships → New**.
- Every field requires a Data Type that defines what kind of data it stores.
- Common data types include Text, Number, Currency, Phone, Email, Date, Date/Time, Checkbox, Picklist, Multi-Select Picklist, Formula, Auto Number, Percent, URL, Text Area, Time and Geolocation.
- Field-Level Security determines which Profiles can view or edit the field.
- Fields can be added to one or more Page Layouts during creation.
- **Required** makes the field mandatory before saving a record.
- **Unique** prevents duplicate values and can be case-sensitive or case-insensitive.
- **External ID** identifies records for integrations, imports and upserts.
- **Auto Number** automatically generates sequential values using a display format (e.g. EN-001, EN-002).
- Page Layout controls how fields are displayed on a record page.
- "Auto add to custom report types" should remain enabled by default unless there is a specific reason to disable it.
